The protocol on one slide

ItemChoice
SignatureECDSA P-256 with SHA-256, raw r and s joined (64 bytes)
EncodingDeterministic CBOR (RFC 8949), strict parser, no trailing bytes
TransportAnimated QR frames (IMQ1), up to 200 bytes each, CRC32 on the whole message
Device checksParse, own device id, recomputed total, six-word fingerprint
Server checksHash, signature, counter, expiry, maker-checker
Limits50 items, 16 or 20 digit accounts, amounts in tiyin

A Python reference implementation passes 31 tests and ships test vectors for the Kotlin and backend code.

Backup: the full spec is in the plan document. Draft protocol, no independent security review yet. The reference implementation covers hostile input, replay, tampering, counter regression, expiry, lock-out, maker-checker and the audit chain.
